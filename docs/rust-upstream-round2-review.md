## Proposal verdicts

### A1 stable-peak tuning — reject this rule; leave tuning unchanged in the first experiment

A forward 50 ms nearest-peak match within3 c removes the bad MIDI57 votes, but **all six MIDI69 vibrato cases still report a bad offset**. Gain.03/phase0 gives **+46.614 c, concentration0.8563, seven votes**. For example, the 853.068 Hz peak moves only2.862 c between the two windows. “Modulated peaks cannot vote” is false.

A 4096-sample window spans170.67 ms, almost a full 5 Hz cycle; bin spacing is5.859 Hz. FM produces sidebands and broad/interfering lobes, not one instantaneous fundamental trajectory. Sideband spacing is5 Hz, and modulation index grows with frequency and harmonic number. A stationary-looking maximum can be a modulation feature. Two endpoints also miss motion between them. A2's peak matching inherits this problem.

Do not replace the rule with an empirically chosen concentration threshold: the bad A1 estimate is more concentrated than the original bad estimate. Raising it enough to reject these examples is not a calibrated tuning repair. Nor should tuning be disabled globally: fresh static −49/−35/0/+35/+49 c controls correctly remain MIDI57 in baseline. Keep those as retention controls.

A simpler *separate ablation* is unique nearest-MIDI assignment within50 c of the tuning-adjusted lattice, with a deterministic tie rule. It closes the gap but cannot correct bad tuning or wide-vibrato identity. Blind modulo100 wrapping inside the current per-MIDI loop would let distant MIDI hypotheses use the same peak; it is unsafe. Do not combine these alternatives or tune thresholds on the failures.
